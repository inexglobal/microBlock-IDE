# ผลตรวจบล็อก microBlock IDE

ตรวจเมื่อ 8 ตุลาคม 2026 ครอบคลุมบอร์ดที่ลงทะเบียนทั้ง 31 บอร์ด และบล็อกที่มีตัวสร้างโค้ดรองรับ 230 ชนิด

| การตรวจ | ผล |
| --- | --- |
| โหลดและแสดงบล็อกด้วย Blockly จริงในเบราว์เซอร์ | ผ่าน |
| ค่าเริ่มต้น ช่องรับค่าว่าง ช่องที่ต่อบล็อก และแต่ละตัวเลือกใน dropdown | 11,701 กรณีผ่าน |
| ตรวจไวยากรณ์โค้ด Python ด้วย `compile()` โดยไม่รันบนอุปกรณ์ | 8,397 กรณีผ่าน |
| การแจ้งเตือน ปิดใช้งาน บันทึก/เปิดไฟล์ และ Undo/Redo | 80 assertions ผ่าน |
| พฤติกรรมของตัวสร้างโค้ดส่วนกลาง | 72 assertions และ 28 กรณี Python ผ่าน |
| ปัญหาเฉพาะบอร์ด | 41 assertions ผ่าน |
| สลับ Pico-X ↔ Arduino Uno, เปิด XML ที่บันทึกไว้ และรักษานิยามจาก extension | 20 assertions ผ่าน |
| ไวยากรณ์ไฟล์ JavaScript ในบล็อก บอร์ด และไฟล์เชื่อมต่อที่เกี่ยวข้อง | 282 ไฟล์ผ่าน |
| สเก็ตช์ตัวอย่างที่สร้างจากตัวสร้างโค้ดจริง | คอมไพล์ผ่าน Arduino Uno / AVR 1.8.8 |

## ปัญหาที่แก้

- แยกสถานะปิดใช้งานอัตโนมัติออกจาก Disable ที่ผู้ใช้เลือก ป้องกันตัวตรวจของ Arduino เปิดบล็อกผิดตำแหน่งกลับขึ้นมา
- ตรวจ `break` / `continue` ตั้งแต่สร้างบล็อกและเมื่อย้าย รองรับลูปของ microBlock และหยุดตรวจที่ขอบเขตฟังก์ชันหรือ callback
- ตรวจ conditional return ให้ตรงกับฟังก์ชันที่ครอบอยู่ รวมถึง `setup()` / `loop()` และ callback ของ Arduino
- ล้างไอคอนเตือนที่ค้างหลังแก้ตำแหน่ง โดยรักษาคำเตือนอื่นของบล็อกไว้
- บันทึกเฉพาะ Disable ที่ผู้ใช้เลือก แล้วคำนวณสถานะอัตโนมัติใหม่เมื่อเปิดไฟล์ เปลี่ยนบอร์ด หรือ Undo/Redo
- ซ่อนรายการใน toolbox ที่ไม่มีนิยามบล็อกหรือตัวสร้างโค้ดสำหรับแพลตฟอร์มปัจจุบัน และแจ้งเตือน/ปิดใช้งานบล็อกที่ไม่รองรับซึ่งอยู่ในไฟล์เดิม
- เติมค่าเริ่มต้นของช่องว่างและ `pass` ให้ callback Python ว่าง เพื่อป้องกันโค้ดขาด argument หรือ body
- แก้การสร้างโค้ด C++ ของการเปรียบเทียบ เลขยกกำลัง เศษจากการหาร ทริโกณมิติ ข้อความ ตัวแปร และชนิดค่าที่ฟังก์ชันคืน
- การสร้างโค้ดไม่เปลี่ยนการเชื่อมต่อของบล็อกตัวแปรอีกต่อไป
- แก้ลำดับ tuple ของ RTC, การ seed แบบไม่ผูกกับขา ADC ของ ESP32, import/call import และ raw code ทั้งสองแพลตฟอร์ม
- คืนค่านิยามบล็อกและตัวสร้างโค้ดของบอร์ดเดิมเมื่อเปลี่ยนบอร์ด เพื่อไม่ให้ Serial ของ Pico-X ปะปนกับ Arduino โดยรักษานิยามที่ extension เพิ่มภายหลังไว้
- เพิ่ม `detachInterrupt` ที่ขาด แก้ความเร็วล้อ M3/M4 ของ Puppy 4WD การเลี้ยวของ POP-32/Hanuman การเล่นโน้ต POP-32 และรูปภาพว่างของจอ
- ลบรายการ Touch ที่บอร์ด POP-32/Hanuman ไม่รองรับ และนิยามจอเก่าของ Uno R4 ที่ไม่มีใช้งาน

## ขอบเขตของผลตรวจ

ทดสอบ toolbox ที่แอปสร้างจริงและบล็อกที่ประกาศพร้อมตัวสร้างโค้ดของแต่ละบอร์ด เลือกแต่ละค่าใน dropdown แยกกัน และมี regression tests สำหรับการต่อบล็อกที่เคยมีปัญหา ผลนี้ไม่ได้ครอบคลุมทุกการจัดวางหรือค่าข้อมูลที่ผู้ใช้สามารถสร้างได้

การตรวจ Python ใช้ compiler ของ Python บนคอมพิวเตอร์เพื่อหา syntax และข้อผิดพลาดด้านขอบเขตคำสั่ง ไม่ได้รันโมดูล MicroPython บนบอร์ด สเก็ตช์ C++ ตัวอย่างคอมไพล์จริงบน Arduino Uno ครอบคลุม operators, ข้อความ, ตัวแปร Boolean, ฟังก์ชัน, ลูปพร้อม break และคำสั่งขา ใช้ Flash 3,778 bytes และ RAM ส่วนกลาง 77 bytes ไม่ได้คอมไพล์ทุก library ของทุกบอร์ดหรือทดสอบกับฮาร์ดแวร์

โฟลเดอร์ `extension` ใน checkout นี้ไม่มี extension ให้ตรวจเพิ่มเติม

## รันตรวจซ้ำ

ใช้ Node.js 18 ขึ้นไป สำหรับชุดทดสอบเบราว์เซอร์ต้องมี Playwright และเบราว์เซอร์ที่รองรับ ส่วน Python checker ต้องมี Python 3

```text
node scripts/check-board-blocks.cjs
node scripts/check-common-blocks.cjs
node scripts/check-block-warnings.cjs
node scripts/check-board-switching.cjs
node scripts/check-all-blocks.cjs --report <path-to-report.json>
```

ตัวแปร environment ที่ตั้งได้:

- `MICROBLOCK_PLAYWRIGHT`: ชื่อหรือ path ของโมดูล Playwright ถ้าไม่ได้ติดตั้งในโครงการ
- `MICROBLOCK_BROWSER_CHANNEL`: เช่น `msedge` เพื่อใช้ Microsoft Edge ที่ติดตั้งอยู่
- `MICROBLOCK_PYTHON`: path ของ Python executable

`check-all-blocks.cjs` บันทึกรายงาน JSON พร้อมโค้ดของแต่ละกรณีและรายละเอียดข้อผิดพลาด โดยไม่เชื่อมต่อหรืออัปโหลดลงบอร์ด
